COMO ADICIONAR UM NOVO RESUMO (mais fácil): clique em "Conectar pasta" no topo e selecione a pasta onde ficam este
índice e todos os seus resumos. Depois disso, entre em Fase → UC → Categoria e use o cartão "+ Adicionar resumo":
arraste o arquivo .html ali (ou escolha pelo seletor), preencha o título e a descrição, e pronto — o arquivo é salvo
na pasta e o índice se atualiza sozinho. Isso funciona em navegadores baseados em Chromium (Opera, Chrome, Edge).

COMO REMOVER UM RESUMO: passe o mouse sobre o card do resumo (dentro de uma categoria ou num resultado de busca) e
clique no "×" que aparece no canto. Com a pasta conectada, você escolhe se quer apagar o arquivo .html também ou só
tirar ele do índice.

COMO ADICIONAR MANUALMENTE (se o navegador não suportar): abra este arquivo em um editor de texto, encontre a lista
GUIDES no final do HTML e copie um bloco existente, trocando title / tag / file / desc / fase / uc. "tag" precisa ser
exatamente PBL, LMF, LPF, TBL ou CLÍNICAS. "fase" e "uc" precisam bater com um id existente em FASES. "file" precisa
ser o nome exato do .html salvo na mesma pasta.

SOBRE AS CAPAS: a imagem que você escolhe em cada bloco fica salva no armazenamento local deste navegador, associada a
este arquivo. Ela continua aparecendo da próxima vez que você abrir o mesmo arquivo neste mesmo navegador, mas não é
copiada para dentro do HTML — se você mover o arquivo para outra pasta, renomear, ou abrir em outro navegador/computador,
vai precisar escolher as imagens de novo.
